# Adoção de Pets 


#  Sobre o projeto
Esse projeto se trata de um site no qual o objetivo é resgatar e proporcionar reabilitação para cães e gatos feridos ou negligenciados, sendo utilizado apenas HTML, CSS e JavaScript puro nessa aplicação.

# Elementos do site
No site, é possível observar botões como: View Adoptable Pets, Donate, subscribe e Apply to Adopt
View Adoptable Pets: É a lista de animalzinhos que você pode adotar disponíveis no abrigo (não disponível essa função no ite, apenas visível)
Donate: é possível apoiar a causa e ajudar nessa missão. Com esse botão, você pode doar e dar uma força para a instituição
Subscribe: para receber atualizações sobre eventos de abrigo, festas de arrecadação de fundos e histórias emocionantes
de animais encontrando seus lares eternos.
Apply to Adopt: é basicamente se cadastrar/registrar para poder adotar os animalzinhos do abrigo

# Páginas do site 
Esse site possui apenas 3 páginas até o momento: a principal/home, a página de sucesso e a view adoptable pets
Principal/home: está diversas informações sobre o site, dados, objetivo, o quê fazem e porquê fazem. Além de ter elementos gráficos que chamam atenção para os pets possíveis de adotar ou informações importantes
Página de sucesso: Você é direcionado para ela quando se inscreve no site ou faz uma doação, é a forma de se agradecer!
View adoptable Pets: Você pode dar uma olhada nos peludinhos mais fofinhos e bonitinhos que estão no abrigo, prontos para serem adotados
